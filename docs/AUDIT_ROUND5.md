## 一、影响论文结论的（已修）

### 1. 四条实验臂用了不同的随机初始化

原来每条臂在训练前都用 `derive_seed(seed, "stage", arm)` 重新播种，意味着 **FedAvg 和 FedDS 的初始权重不同**。2×2 对照里混进了初始化噪声，臂间差异不完全是"方法"造成的。

改为四条臂共用 `derive_seed(seed, "stage", "fedds")`：**同一初始权重、同一客户端顺序、同一 dropout 流**，差异只来自标签与聚合方式。

同时在每臂的 `summary.json` 里记录 `initial_state_sha`，论文表格可以直接证明"四条臂起点相同"。新增测试断言「同种子不同臂 → 初始哈希相同」「不同种子 → 哈希不同」。

### 2. Spearman 相关对并列值处理错误

`spearman()` 用 `argsort` 的顺序当秩次，**并列值会拿到不同的连续秩**。而客户端噪声估计里，干净的客户端估计值**全都是精确的 0.0**——并列是常态，不是边界情况。

改用平均秩（与 `scipy.stats.rankdata` 一致），并用 5 组重并列数据与 `spearmanr` 对拍，误差为 0。

这直接影响论文里的 `spearman_estimated_vs_true` 这个数字。

## 二、崩溃或静默错误（已修）

| # | 问题 | 场景 | 修复 |
|---|---|---|---|
| 3 | `torch.stack([])` 崩溃 | 公共集为空（`public_ratio` 过小或数据集太小） | `materialize` 支持空输入；`pipeline` 在切分后显式检查公共集与测试集非空 |
| 4 | DS 对非法输入报错不友好 | 预测越界或空矩阵 → 索引错误 | 入口校验：空数组、越界标签直接给出可读错误 |
| 5 | 纠错失效时没有任何提示 | 置信度阈值过高导致 0 个标签被改，或改错比改对多 | 非合成数据时打印明确警告（"本次结果只能当冒烟"） |
| 6 | 没有 torchvision 时静默丢掉数据增强 | 环境缺依赖 | 训练变换降级时打印 `RuntimeWarning` |

## 三、随机化属性测试（新增 9 个）

不再只测手挑的样例，改为扫参数：

| 测试 | 覆盖 |
|---|---|
| 数据守恒扫描 | 8 组随机 (K∈{5,10,20,50}, α∈{0.1,0.5,10}, ratio∈{0.05,0.1,0.2})，断言互斥、并集、注噪误差 ≤ 半样本 |

| Spearman 常数输入 | 必须返回 NaN 而不是 0 |
| GMM | 常数输入 → 全部判干净；双峰 → 分离正确 |
| LID | n∈{2,5,40,600} 形状与有限性；单点返回 0 |
